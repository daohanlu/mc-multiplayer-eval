# solaris_fvd

Frechet Video Distance (FVD) evaluation for Solaris rebuttal generations. Each
input video is a 1280×704 side-by-side mp4 produced by the generation pipeline
upstream; this repo crops it into four 640×352 quadrants, extracts I3D features
per quadrant, and computes FVD between Generated and Ground-truth.

## Quadrant convention

| q | content     | position     |
|---|-------------|--------------|
| 0 | GT  Bot1    | top-left     |
| 1 | Gen Bot1    | top-right    |
| 2 | GT  Bot2    | bottom-left  |
| 3 | Gen Bot2    | bottom-right |

Three FVD numbers are reported per experiment: Bot1 (`q0 vs q1`),
Bot2 (`q2 vs q3`), and Mixed (`q0+q2 vs q1+q3`).

## Layout

```
compute_features.py     I3D feature extraction (GPU). 1 quadrant of 1 experiment per run.
compute_fvd.py          FVD between two sets of .npz feature files (CPU, fast).
bash_cmds/
  fvd_features.sh       24 jobs (6 experiments × 4 quadrants) for makesbatch.
  fvd_compute.sh        Local loop computing all 18 FVDs (3 per experiment).
sbatch_files/           Generated by makesbatch from fvd_features.sh.
slurm_outs/             SLURM logs.
outputs/<exp>/q{0..3}.npz   Per-quadrant features + mu/sigma.
models/i3d_torchscript.pt   I3D weights (auto-downloaded if missing).
```

The six experiments compared (input dirs under
`/scratch/dl3957/rebuttal_generations/.../step_0001200_duet/`):
`dmd_cont, v2_blk, v2_flag, v2_nokv, v2_reg, v2_scratch`.

## End-to-end run

Setup (once):

```bash
cd /scratch/$USER/solaris_fvd
uv venv && uv pip install av huggingface_hub torch numpy scipy tqdm
```

### 1. Feature extraction (GPU, ~20 min/job, 24 jobs)

```bash
makesbatch --time 1 --ngpu 1 --l40s --bash_file bash_cmds/fvd_features.sh
```

Each job writes one `outputs/<exp>/q{0,1,2,3}.npz` (`features [N,400], mu [400],
sigma [400,400]`).

Single-job manual invocation (smoke test):

```bash
.venv/bin/python compute_features.py \
    --data_dir /path/to/step_0001200_duet \
    --quadrant 0 \
    --output outputs/test/q0.npz
```

### 2. FVD computation (CPU, seconds)

After all 24 `.npz` exist:

```bash
bash bash_cmds/fvd_compute.sh
```

Or one pair manually:

```bash
.venv/bin/python compute_fvd.py \
    --features1 outputs/v2_flag/q0.npz \
    --features2 outputs/v2_flag/q1.npz
```

`--features1` / `--features2` accept multiple paths; they are concatenated
before computing mu/sigma (used for the Mixed case).

## Notes

- I3D model: `flateon/FVD-I3D-torchscript` (the StyleGAN-V port of the
  TF-Hub Kinetics-400 InceptionV1 — canonical FVD backbone).
- Feature dim is 400 (logits). All frames per video are used by default
  (`--num_frames 0`); pass a positive int to uniformly subsample.
- Inputs must match the glob `video_*_side_by_side.mp4` and be 1280×704.
